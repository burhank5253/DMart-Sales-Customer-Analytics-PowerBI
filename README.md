# DMart Sales & Customer Analytics — Power BI

## 📊 Project Overview

This project presents an interactive **DMart Sales & Customer Analytics Dashboard** developed using Microsoft Power BI.

The objective of the project is to analyze sales performance, customer behavior, order status, cancellations, returns, payment methods, and sales trends using a transactional dataset containing approximately **25,000 orders**.

The project demonstrates how raw business data can be transformed into interactive dashboards and actionable business insights.

## 🎯 Business Objectives

* Analyze overall sales performance
* Monitor total orders and average order value
* Analyze cancellation and return rates
* Identify sales trends over time
* Compare sales across product categories
* Analyze payment method performance
* Understand customer age-group behavior
* Analyze order and delivery patterns
* Support data-driven business decisions

## 📈 Dashboard Analysis

### Sales Performance

The dashboard analyzes overall sales performance using key metrics such as total sales, total orders, and average order value.

### Monthly Sales Trend

A year-month analysis helps identify changes in sales performance over time and highlights potential seasonal patterns.

### Category Analysis

Sales are compared across different product categories to identify stronger and weaker-performing categories.

### Customer Analysis

Customer age groups are analyzed to understand which customer segments contribute most to sales.

### Payment Method Analysis

The dashboard compares order and sales performance across different payment methods.

### Order Status Analysis

Order statuses are analyzed to understand completed, cancelled, returned, and other order outcomes.

### Cancellation & Return Analysis

Cancellation and return rates are monitored to identify areas that may require further operational investigation.

## 🎛️ Interactive Dashboard

The Power BI dashboard includes interactive visuals and filters that allow users to explore the dataset from different business perspectives.

Users can analyze:

* Sales trends
* Categories
* Customer segments
* Payment methods
* Order status
* Cancellations
* Returns

## 🧮 DAX Measures

Examples of measures developed for the project include:

```DAX
Average Order Value =
DIVIDE(
    [Total Revenue],
    [Total Orders],
    0
)
```

Additional DAX calculations were created for sales, orders, cancellation rate, return rate, and other analytical metrics.
